

# Nadine Strella's Portfolio

✨ https://nadinestrella.vercel.app/

## About this project

This is the personal portfolio of Nadine Strella, a web developer specialized in modern technologies such as React, Next.js, TypeScript, and Tailwind CSS.
The purpose of this site is to showcase her professional profile, skills, featured projects, work experience, and education.

## Technologies Used

- HTML5

- CSS3 (Tailwind CSS)

- JavaScript (ES6+)

- React

- Next.js

- TypeScript

- Node.js

## Features

- Introductory page with personal information.

- Technical skills section.

- Portfolio showcasing completed projects.

- Summary of education and professional experience.

- Direct links to GitHub and downloadable CV.

- Responsive and modern design.
